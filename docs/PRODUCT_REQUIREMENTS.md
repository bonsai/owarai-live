# OWARAI MUSEN プロダクト要求（PRD）

> 何を作るか・誰のためか・何が必要かを定義する。実装の詳細は `docs/DB_STRATEGY.md`、数値評価は `docs/KPI.md`、概念は `aw.md`。

## 1. 製品の核（1文）
**今日・今週、東京で無料〜500円で行けるお笑いライブを、公式情報を起点に確実に見つけられる検索サービス。**

## 2. ペルソナ
- プライマリ: 東京・近郊で「気軽にライブを見たい」人。空き時間は平日夜・週末。無料〜500円が行動範囲。
- セカンダリ: 学生・若手中心で予算を抑えたい層。はじめての現場探しにも使う。

## 3. ユーザーニーズ（「私は何が必要か」）
1. **価格が確実**: 行こうと思った後で「実は6,000円」の裏切りがない（Ticket price_yen 確定）
2. **日時が確実**: 開催日・開演時刻が間違っていない（date / start_at 確認済み）
3. **行く前の判断材料**: どこで誰がやるか（会場・出演者・シリーズ）で選びたい
4. **裏取り**: 公式出典で確認できる（source_url・重複排除・変更に強い）
5. **探すコストが低い**: 今日 / 今週 / 会場 / 価格フィルタが一瞬で効く
6. **データが新鮮**: 先週の開催情報で外さない（毎日自動収集）

## 4. プロダクト要求（PRD）

### Must（これを満たさないと製品にならない）
| ID | 要求 |
|----|------|
| F1 | 日付×開演順の一覧で、無料〜500円のイベントを表示 |
| F2 | 価格フィルタ: 無料 / 500円以内 / 1000円以内 |
| F3 | 日付・会場・芸人名・イベント名・主催者で検索 |
| D1 | 表示イベントは価格・日時・会場・公式URLが**確認済み** |
| D2 | 価格不明・未確認は一覧に出さない（`confidence=source_confirmed` のみ） |
| D3 | 同一イベントの重複を出さない（provider+id 正規キー / dedupe） |
| O1 | 毎日自動収集が失敗しない（search-agent PASS、6連敗 NG） |
| U1 | 「今日」「今週・7日間」が1タップで効く |

### Should（満たせば差別化になる）
| ID | 要求 |
|----|------|
| S1 | 会場での絞り込み（新宿ブリーカー・サンガイノリバティ 等） |
| S2 | シリーズ理解（RAGS TO RICHES・パワーオブフリー が Series として見える） |
| S3 | 週末（土日）の選択肢が平日同等以上にある |
| S4 | 定常開催（下北GRIP 毎日3部制 等）が自動で載る |
| S5 | 「公式リンク」の出所表示と、所属未確認の区別（confidence の表示） |

### Want（将来の拡張）
| ID | 要求 |
|----|------|
| W1 | Relation を使った意味検索（「幕張メッセで過去に開催されたイベント」等） |
| W2 | 寄席・講談・浪曲・吉本劇場など専門DB を接続（#1/#8） |
| W3 | API 公開・stage-search / BQML 連携（分析・再利用） |

## 6. Non-goals（今回作らない）
- 有料・高額（1,000円超）イベントの網羅
- チケット購入代行・決済
- SNS連携・プッシュ通知
- 全国展開（東京圏に限定）

## 7. 品質（受け入れ基準の雰囲気）
- サイト表示の全イベントに公式出典URLがある
- 500円超のイベントが一覧に出ない
- search-agent の連続失敗（≥2回）を検出したら復旧するまでブロッカー
- モバイルで1タップ以内に「今日」「今週」を選べる
